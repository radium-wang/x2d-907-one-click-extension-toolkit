## 项目简介 / Project overview

X2D/907 一键扩展功能工具包是面向第一代哈苏 X2D 100C 与 907X & CFV 100C 的免费实验性项目。通过 macOS 和 Windows 桌面程序，它为支持的相机提供连续自动对焦、追踪自动对焦、人眼识别、对焦速度调节和后屏自动亮度等可选功能；X2D 100C 还支持像素位移。具体适配范围、安装与恢复方法、版本下载请以组织仓库的最新说明为准。

欢迎更多开发者加入，在组织仓库交流研究发现、改进代码与文档。无论是功能建议、使用反馈还是遇到的问题，都欢迎[提交 Issue](https://github.com/Gothenburg-R-D-Team/x2d-907-one-click-extension-toolkit/issues)；也欢迎通过 [Pull Request](https://github.com/Gothenburg-R-D-Team/x2d-907-one-click-extension-toolkit/pulls) 参与完善项目。

X2D/907 One-Click Extension Toolkit is a free, experimental project for the first-generation Hasselblad X2D 100C and 907X & CFV 100C. Its macOS and Windows desktop apps offer optional continuous and tracking autofocus, eye recognition, focus speed controls, and automatic rear-screen brightness for supported cameras. Pixel Shift is available on the X2D 100C. See the organization repository for current compatibility, installation and restoration instructions, and downloads.

More developers are welcome to join the project and share research or improve its code and documentation. Please [open an Issue](https://github.com/Gothenburg-R-D-Team/x2d-907-one-click-extension-toolkit/issues) for ideas, feedback or problems, or contribute a [Pull Request](https://github.com/Gothenburg-R-D-Team/x2d-907-one-click-extension-toolkit/pulls) in the organization repository.
