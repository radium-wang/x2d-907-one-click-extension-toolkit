English quick start
1. Extract the entire ZIP and double-click x2d-907一键扩展功能-工具包.exe. Allow the Windows administrator prompt.
2. Turn on one supported camera, connect a USB data cable, then click Connected. The app prepares only the camera factory Interface 3 driver and checks the camera.
3. Once checks pass, click Install or Restore original. Keep the camera powered and connected until completion is confirmed. Tap Skip on the camera if prompted.
4. Open Tweaks (English install) or 耍起功能 (Chinese install) at the end of the camera's main menu. Turn on its master switch, then AF-C or the focus speed buff.
5. Do not remove the lens while the focus buff is on. Turn it off before changing lenses.
Windows 10 / 11 x64; original X2D 100C / 907X & CFV 100C firmware 4.2.0 only.
Automatic driver setup and the 907X menu update still await device verification. ADB is a separate interface and may require its own driver.


适用：Windows 10 / 11，64 位；第一代 X2D 100C、907X & CFV 100C，原厂固件 4.2.0。
不适用于 X2D II、907X 50C 或其他固件。

使用步骤
1. 完整解压 ZIP 到新文件夹，双击“x2d-907一键扩展功能-工具包.exe”。Windows 会请求管理员授权，请允许。不需要右键选择管理员启动，不要单独移动 EXE。
2. 相机开机，用数据线连接电脑，只连接一台相机。相机屏幕提示连接方式时，可选择“大容量存储”。
3. 点击“已连接”。程序先检查相机的工厂 Interface 3 驱动；已绑定 WinUSB 时直接使用，缺少时自动准备。此步骤仅准备电脑驱动，尚未安装相机功能。
4. 等相机文件与状态检查通过，安装及恢复按钮才会启用。点击“一键安装”，等待备份、安装和重启校验完成。如相机屏幕出现“跳过”，请点击“跳过”，继续保持连接。
5. App 报告安装完成后可以拔线。相机主菜单末尾进入“耍起功能”：X2D 默认第 12 项，907X / CFV 默认第 11 项。先开启总开关，再开启 AF-C 或对焦加速 buff。
6. 需要撤回时，重新连接并点击“已连接”，检查通过后点击“一键恢复原状”，等待恢复和重启校验完成后再拔线。

开启对焦 buff 后切勿取下镜头。
更换镜头前，请先关闭对焦加速 buff。

本版更新
自动准备工厂接口 WinUSB 驱动，并在双击启动时请求管理员授权。
907X 的原厂主菜单有 10 项，缺少 X2D 的机身防抖项；新版按实际菜单末尾追加入口，保留原厂顺序和按钮行为。
安装成功校验增加实际菜单挂接回执，避免仅服务启动就显示菜单安装成功。
保留 0.3.0 的修正：AF-C 功能开启后，在拍摄界面选 AF-S 或 MF，附加开机服务不再强制切回 AF-C。
已知旧版可直接“一键安装”升级。程序先恢复旧版并重启核验，再安装新版并再次重启；中间不要拔线。升级后请重新开启所需功能。
恢复仅接受本版与登记旧版的精确内容；未知版本拒绝覆盖，不要混用新旧安装包文件。

自动驱动范围
仅允许一台相机的精确工厂接口：
X2D：USB\VID_2756&PID_0009&MI_03
CFV 100C：USB\VID_2756&PID_000A&MI_03
程序使用 libwdi 1.5.1，生成针对该接口的安装包，并使用 Windows 自带 WinUSB。
libwdi 会为该驱动目录签名并安装所需证书；未关闭驱动签名校验、UAC 或系统还原设置。
不会替换 USB Composite Device、存储、网络、ADB 或其他设备接口。未找到精确接口或连接多台目标时停止，安装和恢复仍禁用。
驱动辅助程序和 DLL 在执行前校验 SHA-256，源代码与许可随包提供。
工厂通信和 ADB 为独立接口。自动准备仅处理工厂 Interface 3；临时 ADB 通道仍需 Windows 能识别对应的 ADB 驱动。
若 ADB 无法识别，保留连接，按具体中文提示检查对应厂商的 ADB 驱动；不要把 ADB 驱动装到工厂接口。
切换通道后 USB 会断开再连接，程序自动等待，无须用拔插加快重连。重启会恢复相机生产 USB 配置。

仅在自动准备失败时使用手动备用方法
从官方 https://zadig.akeo.ie/ 下载 Zadig，Options → List All Devices。
选择相机名称末尾的“(Interface 3)”，核对 USB ID：X2D 为 2756 / 0009 / 03，CFV 为 2756 / 000A / 03。
只有完全对应才选择 WinUSB 并点击 Install Driver / Replace Driver；当前已是 WinUSB 则无须重复安装。
找不到对应 Interface 3 时停止，不要选择 Mass Storage 或其他接口。
相机屏幕的“大容量存储”是连接方式，和 Zadig 的 Mass Storage 接口条目不同。

故障与反馈
首次排查只点击“已连接”，反馈底部最后完整中文提示、应用版本、相机型号、固件及 Windows 版本。
没有弹窗也可能正常启动；程序依据真实 ADB 结果显示提示，不要求处理未出现的窗口。
失败时不会显示成功，重新检查后可以恢复已知安装。程序不自动结束其他 ADB 服务或修改安全软件设置。
操作日志保存于 %LOCALAPPDATA%\X2DPlay\latest.log。不要反馈设备序列号。
本包自带运行组件，不需要另装 Python。程序尚无发行者签名。

软件更新 / App updates
打开“设置”，点击“手动检查更新”；发现新版后，点击“下载并安装更新”。校验通过后 App 会退出、安装并重新打开；上一版保留在应用旁的更新备份目录。
Open Settings, click Check for Updates, then Download and Install Update. The verified app update installs after exit and relaunches; the previous app is retained beside the installation.
相机操作期间不能更新。更新只替换电脑端 App，相机扩展需再点击“已连接 → 一键安装”更新。
Updates are disabled during camera operations. To update the camera extension afterward, use Connected → Install.

0.4.1 修正菜单回执刷新。若提示文件已安装但菜单回执待刷新，请在相机点击“跳过”并打开主菜单，再点击 App 的“已连接”。0.3.3 可直接安装升级；恢复与重启期间保持连接。
Version 0.4.1 refreshes menu receipts after service restarts. If files are installed but the receipt is pending, tap Skip and open the camera main menu, then click Connected again. Known 0.3.3 installs can be upgraded; stay connected during restoration and reboot.

自动检查更新默认开启，可在设置中关闭，重启后保留选择。自动检查只查找新版，不会自动下载或安装；关闭后仍可手动检查。
Startup update checks default to on. Disable them in Settings; the choice survives restart. Downloads and installation remain manual, and manual checks still work when automatic checks are off.
安装时按 App 语言选择相机菜单。需要恢复并重新安装时，按目标语言弹窗确认；取消不修改相机，完成后需重新开启所需功能。
Install selects the camera menu language from the app. Restoration before reinstallation requires confirmation in the target language. Cancel leaves the camera unchanged; re-enable the features you need after completion.
