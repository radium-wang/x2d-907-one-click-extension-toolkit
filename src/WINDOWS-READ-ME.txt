English quick start
1. Extract the entire ZIP and double-click x2d-907一键扩展功能-工具包.exe. Allow the Windows administrator prompt.
2. Turn on one supported camera, connect a USB data cable, then click Connected. The app prepares only the camera factory Interface 3 driver and checks the camera.
3. Once checks pass, select the wanted features and click Install selected features, or Restore original. Keep the camera powered and connected until completion is confirmed. Tap Skip on the camera if prompted.
4. Open Tweaks (English install) or 耍起功能 (Chinese install) at the end of the camera's main menu. Turn on its master switch, then AF-C, the focus speed buff, or auto rear screen brightness. Select Traditional Chinese in Settings before Install for Traditional Chinese camera text.
5. Focus acceleration works by tripling lens motor speed. Not recommended for older lenses.
Windows 10 / 11 x64; original X2D 100C / 907X & CFV 100C firmware 4.2.0 only.
Automatic driver setup and the 907X menu update still await device verification. ADB is a separate interface and may require its own driver.


适用：Windows 10 / 11，64 位；第一代 X2D 100C、907X & CFV 100C，原厂固件 4.2.0。
不适用于 X2D II、907X 50C 或其他固件。

使用步骤
1. 完整解压 ZIP 到新文件夹，双击“x2d-907一键扩展功能-工具包.exe”。Windows 会请求管理员授权，请允许。不需要右键选择管理员启动，不要单独移动 EXE。
2. 相机开机，用数据线连接电脑，只连接一台相机。相机屏幕提示连接方式时，可选择“大容量存储”。
3. 点击“已连接”。程序先检查相机的工厂 Interface 3 驱动；已绑定 WinUSB 时直接使用，缺少时自动准备。此步骤仅准备电脑驱动，尚未安装相机功能。
4. 等相机文件与状态检查通过，安装及恢复按钮才会启用。选择所需功能后点击“安装所选功能”，等待备份、安装和重启校验完成。如相机屏幕出现“跳过”，请点击“跳过”，继续保持连接。
5. App 报告安装完成后可以拔线。相机主菜单末尾进入“耍起功能”：X2D 默认第 12 项，907X / CFV 默认第 11 项。先开启总开关，再开启 AF-C、对焦加速 或“在亮度菜单中加入自动亮度”。自动亮度开关和显示屏最高亮度位于“显示 → 亮度”；圆球设置上限，白线显示当前输出。
6. 需要撤回时，重新连接并点击“已连接”，检查通过后点击“一键恢复原状”，等待恢复和重启校验完成后再拔线。

对焦加速通过将镜头转速提高三倍实现，不建议老镜头用户开启。

自动驱动范围
仅允许一台相机的精确工厂接口：
X2D：USB\VID_2756&PID_0009&MI_03
CFV 100C：USB\VID_2756&PID_000A&MI_03
程序使用 libwdi 1.5.1，生成针对该接口的安装包，并使用 Windows 自带 WinUSB。
libwdi 会为该驱动目录签名并安装所需证书；未关闭驱动签名校验、UAC 或系统还原设置。
不会替换 USB Composite Device、存储、网络、ADB 或其他设备接口。未找到精确接口或连接多台目标时停止，安装和恢复仍禁用。
驱动辅助程序和 DLL 在执行前校验 SHA-256，源代码与许可随包提供。
工厂通信和 ADB 为独立接口。自动准备仅处理工厂 Interface 3；临时 ADB 通道仍需 Windows 能识别对应的 ADB 驱动。
若 ADB 无法识别，保留连接，按具体中文提示检查对应厂商的 ADB 驱动；不要把 ADB 驱动装到工厂接口。
切换通道后 USB 会断开再连接，程序自动等待，无须用拔插加快重连。重启会恢复相机生产 USB 配置。

仅在自动准备失败时使用手动备用方法
从官方 https://zadig.akeo.ie/ 下载 Zadig，Options → List All Devices。
选择相机名称末尾的“(Interface 3)”，核对 USB ID：X2D 为 2756 / 0009 / 03，CFV 为 2756 / 000A / 03。
只有完全对应才选择 WinUSB 并点击 Install Driver / Replace Driver；当前已是 WinUSB 则无须重复安装。
找不到对应 Interface 3 时停止，不要选择 Mass Storage 或其他接口。
相机屏幕的“大容量存储”是连接方式，和 Zadig 的 Mass Storage 接口条目不同。

0.4.12 pre-installation checks
The installer checks the specified stock UI, focus and display files and installation records. Unknown modifications stop the operation. Restore stock 4.2.0 with the original modification tool, then check again. This toolkit will not overwrite or restore unknown modifications. The check does not establish that the entire firmware or live memory is stock.
Focus acceleration can be installed, but older-lens users are advised not to enable it in the camera. Camera payloads are unchanged from 0.4.9; selectable installation is not included.
